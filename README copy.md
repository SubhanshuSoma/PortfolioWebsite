# Subhanshu Soma — Portfolio

Responsive portfolio built with HTML, CSS, and JavaScript. No build step required.

## Preview

Open `index.html`, or run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Features

- Teal editorial design and monogram hero
- Accessible mobile navigation, Escape dismissal, and active section highlighting
- Project filters with screen-reader announcements
- Original resume download and embedded PDF viewer
- Reduced-motion support, skip link, and content available without JavaScript
- Updated Technical Project Manager internship and CandidATS project

## Files

- `index.html`: content
- `styles.css`: responsive layout
- `script.js`: navigation and project filters
- `assets/resume.pdf`: supplied resume, unchanged

GitHub links retain the profile URL supplied in the original website and resume. Replace project links with verified repository URLs when available. Replace the SS monogram with a headshot if desired.

Hosting is not enabled automatically. The files can be served by any static web server.
